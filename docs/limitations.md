# Limitations

This page is part of the product, not an appendix.

## Scientific

- The phase map is a **declared** representation. Pair distances are
  functions of ordinate gaps plus the arithmetic measure. That is an
  identifiability boundary, not a discovery of independent observations.
- Apparent high rank is **torus closure**, not a new local manifold.
- Discrete-zero kNN does **not** recover the analytic tangent. Mean gaps
  already wind the fastest primes. The certificate is a micro-window on Φ.
- Function-sheaf restriction composes by definition. A zero residual
  there is not a certificate. The cellular test is **δ² = 0**.
- Pairwise Procrustes is a connection. It is not a higher cellular sheaf.
- Holonomy is curvature. Nontrivial holonomy is not automatically invalid.
- GUE and Poisson test **spectral spacing**. They are not industrial nulls.
- `p ≥ 0.05` is not proof of no effect. The manuscript `p_emp = 0.70`
  is a failed *promotion*, not a proof the construction is empty.
- Persistence is metric-derived. It contains no information beyond the
  metric once the filtration is fixed.
- Betti patterns for stick-slip / whirl / bounce are **candidates**.
- A geodesic is shortest under a chosen metric. It is not automatically safe.
- Geometry does not certify physical interlocks.

## Product

- There is no live rig connector and no closed-loop control.
- Drill and wellbore walks are **synthetic**. The UI must say so.
- 10 Hz / sub-100 ms figures from the GT-MoE deck are **targets**, not
  measurements in this repo.
- Provenance uses djb2, not SHA-256.
- Auth is preview-grade (better-auth + optional PGLite). Not an SSO product.
- `src/lib/multiplayer` is leftover template. This is not a networked instrument.
- No ISA/IEC 62443 claim is made.
- No RH, Hilbert–Pólya, or physical-Hamiltonian claim is made.

## What would have to be true before we say more

- Independent recomputation of every manuscript table cited in the UI.
- Holdout on unseen wells / rigs / formations before L3 or L4 promote.
- Measured latency distributions on named hardware.
- SHA-256 manifests if certificates become lab records.
- Hazard analysis before any advisory is allowed near a control system.
