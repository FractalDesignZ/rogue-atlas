# Rogue Atlas

See the geometry. Test the claim. Deploy the evidence.

An evidence-aware geometric intelligence platform. Sequential data becomes
geometry and topology. The instrument then distinguishes structure imposed
by the representation from structure independently supported by the data.

**Meridian** is the scientific kernel (zeta reference, rank-one orbits,
damped Weyl operators). **Atlas Research / Operations / Audit** are the
three rooms. **GT-MoE Rogue** is the first operational vertical — advisory
only, never a certified controller.

Finite certificates. Not RH. Not a new physical law. A curved 3D
projection is not an intrinsic manifold.

**Read [docs/limitations.md](docs/limitations.md) first.**

## Evidence statuses

Exact · Certified · Observed · Validated · Failed · Speculative

A sophisticated graph is not a finding because it is pretty. The held-out
prime experiment was allowed to fail (`p_emp = 0.70`) without touching
the exact identities.
