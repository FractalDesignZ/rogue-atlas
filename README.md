# Meridian

Phase-recurrence discovery studio. Exact geometry, frozen tests, and
cross-domain synthesis.

Meridian implements the constructions and boundaries of *Arithmetic
Phase-Recurrence Geometry and Prime-Perturbed Weyl Operators*: rank-one
arithmetic orbits, recurrence graphs, prime-perturbed Weyl operators,
and hold-out protocols that refuse to treat a construction as a finding.

Open the adapter, walk a field, freeze a cell, export the certificate.
Finite necessary conditions only — not a proof of RH.

Install from the in-app guide (Add to Home Screen) after signing in to
keep certificates.
