# Paper ingest

Read to extract **constructions, bounds, and non-claims**. Ignore the
abstract's poetry until the theorems are in a list.

## 1. What to pull (in this order)

| Pull | Example | Product fate |
| --- | --- | --- |
| Identity | "the orbit is rank-one, speed √μ₂" | Claim class **identity**. Compute it. Do not test it. |
| Bound | "Dirichlet recurrence, first reversal" | Show the number. Label the assumption (cutoff Q). |
| Certificate | "δ² = 0", "restrictions compose" | A **gate**. Fail closed. |
| Empirical protocol | "held-out prime vs GUE" | A **frozen cell** with a justified null. |
| Explicit non-claim | "not a Hilbert–Pólya operator" | **Excluded** row in the ledger. Say it on the glass. |
| Domain lift | wellbore holonomy, drill Betti | Same gates. New series. No new epistemology. |

If the paper does not contain a non-claim, invent the honest one:
*this construction does not prove the hypothesis it was drawn to illuminate.*

## 2. Correction pass (mandatory)

Papers and companion notes routinely mix layers. Correct **before** you
draw.

| Mix-up | Correction |
| --- | --- |
| Holonomy "failure" | Holonomy **is** curvature F. The sheaf test is δ² = 0. |
| PCA rank | Chosen view, not discovered dimension. |
| Time as a new axis | Time is already the evolution coordinate. Typed, never converted in silence. |
| GUE as physics | Spacing null. Not a field theory. Not a drill null. |
| Pairwise Procrustes as a sheaf | Connection only, until restrictions compose. |
| Travel cost vs stretched metric | Path cost ∫ ds / v falls toward high value. Dual of g_v = v · g. |
| Type I vs Type II | Fisher singularity ≠ valuational cliff. Count separately. |

Write corrections on the Method page in the same turn you implement them.
A silent correction is a future hallucination.

## 3. The reproduction bar

Pick **one** number the paper publishes and recover it in the engine.

- Zeta tangent cosine in native Φ-space → Studio geometry (paper ~0.991).
- Plane analog (adapter field) → labeled **analog**, never sold as Φ-space.
- δ², restriction composition, Bianchi ΣK ≈ 0 → sheaf module.
- Weyl RMSE reduction → operator pane.

No reproduction → no "based on this paper" in the landing copy.

## 4. Multi-paper synthesis

When the user drops several PDFs:

1. **One refuse** for the product (do not union every author's ambition).
2. **Tag each paper** as identity source, correction source, domain lift,
   or commercialization spec.
3. **Promote only what survives the gate.** A drilling Betti number does
   not inherit zeta's GUE protocol. A CST open set does not inherit a
   Lorentzian metric.
4. **Name the seams.** "This is the wellbore lift of open-curve holonomy,
   not the zeta kernel."

Commercialization blueprints are **UX and stack specs**, not theorems.
Implement their pipeline and audit UX. Do not implement a Python service
the preview cannot run.

## 5. What not to ingest

- Private kernels, unpublished RMSE, Kaggle scores you cannot recompute.
- Author affiliation as evidence.
- Figures as results (redraw from the construction).
- "Geometric Unity" or any named physics as a discovered dimension.
  Discretizations are **tests of a discretization**, not of the physics.
